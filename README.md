Patrón de diseño implementado: Composite

En este proyecto se implementa el patrón Composite para la construcción del formulario de entrevista.

Las clases DatosPersonales, Salud, Experiencia y Motivación funcionan como componentes individuales del formulario. Cada una representa una sección distinta encargada de gestionar un tipo específico de información.

La clase FormularioEntrevista actúa como el objeto compuesto, ya que integra y organiza todas estas secciones en una estructura unificada. Esto permite tratar cada grupo de datos tanto de forma individual como como parte de un todo, cumpliendo con la lógica del patrón Composite.
