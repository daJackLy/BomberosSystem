
================================================================================
                    SISTEMA DE GESTIÓN DE VOLUNTARIOS
================================================================================

DESCRIPCIÓN:
------------
Aplicación de escritorio desarrollada en Java para gestionar el registro y 
administración de voluntarios. Permite validar edades, generar autorizaciones 
notariales para menores y mantener un control de postulantes.


REQUISITOS DEL SISTEMA:
-----------------------
- Java JDK 8 o superior
- Sistema operativo: Windows, Linux o macOS
- 2 GB de RAM mínimo
- 100 MB de espacio en disco


INSTALACIÓN:
------------
1. Descargar el proyecto completo
2. Abrir con NetBeans o tu IDE favorito
3. Compilar el proyecto
4. Ejecutar la clase principal


CÓMO USAR:
----------
1. Ejecutar el archivo .jar o desde el IDE
2. completar el formulario y guardarlo


FUNCIONALIDADES PRINCIPALES:
----------------------------
- guardado de archivos
- Subida de archivos
- Control de autorización notarial para menores de edad
- Interfaz gráfica intuitiva con Swing
- Validación de datos en tiempo real


TECNOLOGÍAS UTILIZADAS:
-----------------------
- Java SE
- Swing (interfaz gráfica)
- Java Time API (manejo de fechas)


PROBLEMAS CONOCIDOS:
--------------------
- Ninguno reportado actualmente



NOTAS ADICIONALES:
------------------
- Asegúrate de tener los permisos necesarios para ejecutar aplicaciones Java
- El formato de fecha depende de la configuración regional del sistema
- Para soporte técnico, contactar al desarrollador
